# Vortex Tier

## File structure
- `index.html` — home page
- `rankings.html` — rankings page
- `styles.css` — website styling
- `icons.js` — mode icon URLs
- `players.js` — player database generated by Admin Panel
- `app.js` — permanent frontend/rendering code
- `admin.html` — private admin panel

## Updating players
1. Open `admin.html`.
2. Log in.
3. Add/edit/delete players.
4. Click **Download players.js**.
5. Replace the old `players.js` on your website with the downloaded file.
6. Do not replace `app.js`.

`app.js` automatically calculates total points and Overall positions from the player data.
